## P2（零训练）

| 实验 | 问题 | 判读规则（事先定） |
|---|---|---|
| M6 | fps=30（64 token/组）是否本身伤精度 | 任一基准上 fps30 − fps2 显著 < 0 且幅度 ≥ 2 点（AUROC 用 0.02） → "30 fps 伤精度，S2 必需"；否则 → "30 fps 不伤，S2 只为计数/回溯" |
| M7 | GDN 记忆跨度 | 记忆跨度 = AUROC 仍 ≥ 0.75 的最大 Δ。`short`（KV 只留 4 s）下 fps30 的跨度 < fps2 的一半 → 高 token 速率压缩了以秒计的记忆，变化驱动写入 / S2 门控训练必需 |
| M8 | 60 min 稳定性 | 连续流 vs 每次重启的 fresh 流（同一探针配对）：最后 10 分钟探针 AUROC 差 ≤ 0.03 且单帧写入延迟 P50 漂移 ≤ 10% → 稳定；否则必须周期性重置或外挂记忆 |
| 部署协议 | 冻结骨干逐题 yes/no 的部署指标基线 | 只报数，不设门槛；同时报 SimpleStream 式 recent4 对照 |
| 线性探针 | 表示里是否有"存在/计数/时间" | 探针 AUROC（存在，宏平均）≥ 生成式 yes/no AUROC + 0.05 → "看见了但说不出"，S1 读出头有空间 |

## P3 / S1（冻结骨干，只训读出）

主臂：S1a = 潜 token + 头（无 LoRA）；S1b = S1a + 问题块 LoRA r=16（视频通路不带 LoRA）。对手：同骨干、同一流状态、同一 token 序列的生成式读出（yes/no 取 logit；时间/计数贪心解码）。

| 能力 | 成功（全部在 fps2 和 fps30 都要成立） | 止损 |
|---|---|---|
| 存在 / 拒答 | 头 AUROC − 生成式 AUROC ≥ +0.05 且显著；头 ECE ≤ 0.05；FPR@召回80% 低于生成式且显著 | 训练完（1600 步 × 每步 4 段视频，约 6.4k 段视频流）头 AUROC ≤ 生成式 + 0.01，或 CI 含 0 → 停 S1 存在头，结论记为"冻结表示里信息不足"，转 P4 |
| 时间（多段） | Charades-STA test mIoU：头 − 生成式 ≥ +5 点且显著 | 头 mIoU < 生成式 → 停 |
| 计数 | RepCount-A test（count so far）：头 OBO − 生成式 OBO ≥ +10 点且显著 | 头 OBO < 生成式 OBO + 3 → 停，计数交给 P4 |
| 哪一个 | 四选一准确率：头 − 生成式 ≥ +5 点且显著 | 头 ≤ 生成式 → 停 |
| N 问吞吐 | N≈20 题一次前向，头读出耗时 ≤ 生成式（逐题解码）总耗时的 1/4 | — |

额外止损：训练 800 步时存在头的 probe_val AUROC 仍 < 0.6 → 中止该臂、检查实现。
LoRA 臂只有在 S1a 未达成功标准、或 S1b 相对 S1a 显著提升 ≥ 0.02 AUROC 时才进入后续推广。

## B 组：视频框（2026-11-22 02:00 写，任何 B 组结果之前）

数据：HC-STVG v2（train / test）、MeViS（mask 转逐帧框）、LaSOT 子集（person / car / dog / cup / bicycle / hand，带语言描述）、RefCOCO（单帧视频回放）。**VidSTG 不用**：它的视频来自 VidOR，而 VidOR 是 NExT-QA 的来源，NExT-QA 在 Video-Index 的来源列表里（`exclusions.json` 的 dataset_excluded）。Ref-YouTube-VOS 的表达式文件在国内镜像上没找到，先不做。

| 实验 | 主指标 | 成功 | 止损 |
|---|---|---|---|
| B1 "现在在哪"框头（64 token/组） | HC-STVG v2 test 逐帧 Acc@0.5（GT 管道时段内）、"不存在"拒答率 | 用图像 v1.4_D_0.8B 头初始化的版本，Acc@0.5 比从头训高 ≥ 5 点且显著 | 两种初始化都 < 20% Acc@0.5 → 64 token 不够，直接转 B2 |
| B2 提问时高分辨率重编码当前帧（256 / 640 token，只进问题块） | 同上 + 单问延迟 | 640 token 比 64 token 的 Acc@0.5 高 ≥ 10 点，单问额外延迟 ≤ 15 ms（G4） | 提升 < 3 点 → 不值得付延迟，保留 64 token |
| B3 时空管道（slot 关键帧框 / 逐组读框） | HC-STVG v2 m_vIoU、vIoU@0.3/0.5 | m_vIoU ≥ 25（参考：TA-STVG 40.2、STVG-o1 41.2；0.8B 冻结骨干先求可用） | m_vIoU < 15 → 停，框交给跟踪器延续 |
| B4 与存在/时间/计数联合训练 | P3 的各项指标 | 存在 AUROC、STA mIoU、计数 OBO 都不退步（配对 bootstrap 的 CI 不低于 −0.01 / −1 点 / −2 点） | 任一项显著退步超过阈值 → 框头单独训练 |
