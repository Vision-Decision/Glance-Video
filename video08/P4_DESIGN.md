# P4 设计草案（0.8B）：先解决"窗口外的事件记不住"

写于 2026-11-22，只是设计，等 S1 出结果、用户确认后才开训。

## 出发点：M7 推翻了零训练下"GDN 状态承载历史"的假设

M7（插入 1 s 文字卡，Δ 秒后问"出现过吗"）在冻结 0.8B 上的结果：事件还在全注意力 KV 里时，AUROC 为 1.0；一旦离开 KV，冻结 GDN 状态几乎读不出来。按预注册的"AUROC ≥ 0.75"，fps2 下的记忆跨度为 4–8 s，fps30 下不到 4 s。分层窗口（4 s 全帧率 + 4–60 s 抽 2 fps）把跨度撑到 32–60 s，正好对应窗口长度。所以长期记忆目前全靠 KV，P4 的第一件事是二选一或组合：让 GDN 学会记（写入门控 + 训练），或者把 KV 做长而不付线性成本。

## 首要对比 A：高 fps 下的写入门控（变化驱动写入）

| 臂 | 写入规则 | 训练 |
|---|---|---|
| A0 | 每帧 64 token 全写（现状） | 无 |
| A1 | 静止 patch 不写：与上一次写入的同位 ViT 特征余弦相似度 > τ 的 token 丢弃，组内 token 数按 {16, 32, 64} 分桶 | 无（零训练，τ ∈ {0.9, 0.95, 0.98}） |
| A2 | A1 + 每组一个可学习的"写入强度"标量，乘到 GDN 的 β（写入门）上，由帧差特征预测 | S2：只训门控头和视频通路 LoRA，2:1 回放 |
| A3 | 固定降采样写入（每 k 帧写一次，k = 15） | 无，作为"便宜但丢时间分辨率"的对照 |

度量：M7 曲线（fps30，KV 只留 4 s 的臂，用来隔离 GDN）；Charades 存在 AUROC 和计数 OBO（不能变差）；每帧写入延迟和每秒写入 token 数。成功标准：A1 或 A2 让 fps30 的 GDN 记忆跨度（AUROC ≥ 0.75）达到 ≥ 30 s，同时存在 AUROC 降幅 ≤ 0.01。

## 首要对比 B：加长 KV 窗口

| 臂 | 全注意力 KV | 说明 |
|---|---|---|
| B15 | 约 15k token：4 s 全帧率 + 4–60 s 抽 2 fps（现状） | 基线 |
| B30 | 约 30k token：4 s 全帧率 + 4–180 s 抽 1 fps | 同样的 token 数换更长的时间 |
| B115 | 约 115k token：60 s 全帧率 | 全帧率窗口上界 |
| B-ds | 15k token，但 4–600 s 的保留按 DeltaS 式 GDN 状态漂移选块（与问题无关） | 不加 token，换"保留什么" |

每个臂都测：M7 曲线（Δ 到 600 s）；单帧写入 P50/P99（split attention，G4 和 A100 各一次）；N=16 问的读出耗时；显存。B115 的写入延迟是否仍在 60 ms 预算内（G4 上 4B 配置 A 的端到端 P99 为 20.8 ms）是决定项。

## 组合与顺序

1. 先跑零训练的 A1、A3、B30、B115、B-ds（只需推理，G4 上约半天）。
2. 如果零训练臂里没有一个能让 fps30 的记忆跨度 ≥ 30 s，再开 A2 的 S2 训练；S2 的视频通路 LoRA 和 2:1 回放按原报告的 P4 配方，遗忘子项降幅 ≤ 1。
3. S1 的读出头不重训，直接接在 P4 的流上评测；头和生成式的差距是否随记忆改善而变化，单独报告。
